## グループ構造を単純に保つ

- 画面は **Screen → Panel → Component** の浅さに合わせる
- AI 生成 HTML の深いネストは採用せず、各画面・パネル文書の親→子に書き直す

---

## リストはデータ駆動

| UI | セル定義 | 繰り返し元 |
|----|----------|------------|
| 調教師候補 | 1行（氏名等） | 検索結果配列 |
| 重賞勝利 | 1行（日付・レース等） | 分析結果配列 |
| ナビ | NavItem | 画面インベントリ（S00 含む。S05 除外） |
| ホーム遷移 | NavCard | 遷移先定義配列（S02 / S01 / S03 / S04 / S06） |

---

## 表示時に再集計しない

チャート・表は ViewModel（SQLite 分析結果の読取）をそのまま描画する。更新パイプラインは S00 / S06 / ヘッダから実行。
