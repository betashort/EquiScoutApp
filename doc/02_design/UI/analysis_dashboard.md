募集馬分析（および将来の比較からの遷移）で共用する分析枠の配置。  
調教師・生産牧場・血統の本文は **各単体画面と同一コンポーネント**（情報設計 §3.1）。

---

## レイアウト

読む順の**既定配置**（情報設計 §2.4）: **募集馬（入力表示）→ 調教師（実データ）→ 生産牧場／血統（骨格）**。  
Body は **2×2 グリッドで 4 パネルを常時表示**する（種類切替で 1 枚だけ出す構成にはしない）。  
配置は **ドラッグ＆ドロップで入れ替え可能**（後述）。`similarity` / `strength_cost` は載せない。

```text
AnalysisDashboard
├─ ToolbarPanel
│    └─ ContextLabel（対象: 入力中の馬／血統キーなど）
└─ BodyPanel（スクロール）
     └─ Grid 2×2（スロット順は並び替え可）
          ├─ [スロット0] … 既定: horse    → HorseProfilePanel
          ├─ [スロット1] … 既定: trainer  → TrainerAnalysisView
          ├─ [スロット2] … 既定: farm     → FarmAnalysisView
          └─ [スロット3] … 既定: pedigree → PedigreeAnalysisView
```

**Body ワイヤ（2×2・既定）**

```text
┌─ 分析 ─────────────────────────────────────────────────────┐
│ 対象: （入力中の馬 / 父 × 母 など）                         │
├────────────────────────────┬───────────────────────────────┤
│ ⠿ 募集馬                   │ ⠿ 調教師                     │
│ HorseProfilePanel          │ TrainerAnalysisView            │
├────────────────────────────┼───────────────────────────────┤
│ ⠿ 生産牧場                 │ ⠿ 血統                       │
│ FarmAnalysisView           │ PedigreeAnalysisView           │
└────────────────────────────┴───────────────────────────────┘
 （⠿ = ドラッグハンドル。ドロップでスロット入れ替え）
```

| 埋め込み | 共用パネル | 中身 |
|----------|------------|------|
| 募集馬 | [`panels/horse_profile.md`](./panels/horse_profile.md) | フォーム入力の読取表示（単体画面なし） |
| 調教師 | [`panels/trainer_analysis.md`](./panels/trainer_analysis.md) | 実データ（賞金／着回／率／距離／重賞） |
| 生産牧場 | [`panels/farm.md`](./panels/farm.md)（本文） | 骨格（単体と同一） |
| 血統 | [`panels/pedigree.md`](./panels/pedigree.md)（本文） | 骨格（単体と同一） |

### 配置の並び替え（ドラッグ＆ドロップ）

| 項目 | 決定 |
|------|------|
| 対象 | 2×2 の **4 スロット間でパネルを入れ替え**（自由配置・サイズ変更はしない） |
| 操作 | 各セル見出し付近の **ドラッグハンドル** を掴んで別スロットへドロップ。ドロップ先と入れ替わる（swap） |
| 既定順 | 左上 `horse` → 右上 `trainer` → 左下 `farm` → 右下 `pedigree` |
| 狭幅 | 1 カラム時も同じ 4 スロット順を縦に並べ、DnD で順序変更可 |
| 状態 | 画面内の UI 状態。永続化は後続で可（サイドバー開閉と同様） |
| 制約 | 4 種は常にすべて表示。削除・追加・重複は不可。DnD は **配置のみ** 変え、各パネルの初期値ソースは変えない |

キーボード操作（ハンドルフォーカス + 矢印／ショートカットでの入れ替え）は実装時に確保する。詳細見た目は [`visual.md`](./visual.md)。

### 初期値（入力した募集馬情報から決定）

「分析を表示」後、各パネルの対象は **左サイドバーの募集馬入力** から決める。配置の並び替えでは対象キーを変えない。別途ダッシュボード内で選び直さない（単体画面への遷移は別導線）。

| パネル | 初期値のソース（HorseEntry） |
|--------|------------------------------|
| 募集馬 | フォーム全体（読取表示） |
| 調教師 | `調教師` |
| 生産牧場 | `生産牧場` |
| 血統 | `父名` / `母名` |

未入力・解決不能なキーがあるパネルは、そのセルだけ Empty / Placeholder（[`visual.md`](./visual.md)）。他セルの表示は妨げない。

## ビジュアル

- ツールバーは控えめ。本文スクロールと分離
- 2×2 のセル区切りは弱め（カード装飾で重くしない）。狭幅時は縦 1 カラムにフォールバック可
- ドラッグ中はドロップ先スロットを控えめにハイライト。ハンドルは常時見えるが主張しすぎない
- 未実装モジュールは `PlaceholderPanel`（[`visual.md`](./visual.md) の状態方針）
- `similarity` / `strength_cost` は載せない（情報設計）
- 埋め込み時の ProfileHeader 省略可否は [`panels/trainer_analysis.md`](./panels/trainer_analysis.md) に従う
