## レイアウト

| 項目 | 決定 |
|------|------|
| デバイス | **デスクトップ優先**（主に Windows、macOS 対応） |
| 全体 | 左ナビ ＋ ヘッダ（タイトル / 更新 / 最終更新）＋ MainContent |
| 読取方向 | 上→下。分析本文は1カラム縦積み（固定） |
| 起動 | MainContent に **ホーム** をマウント |

```text
┌──────────────────────────────────────────────────────────┐
│ EquiScout          [更新]  最終更新: YYYY-MM-DD HH:mm     │  ← ヘッダ
├──────────┬───────────────────────────────────────────────┤
│ ホーム   │                                               │
│ 募集馬   │              MainContent                      │  ← 各 Screen
│ 調教師   │                                               │
│ 生産牧場 │                                               │
│ 血統     │                                               │
│ 設定     │                                               │
└──────────┴───────────────────────────────────────────────┘
     ↑ グローバルナビ（§2.1 画面インベントリ順。先頭＝ホーム）
```

```text
AppShell
├─ HeaderBar（タイトル / UpdateShortcut / UpdateStatusChip）
├─ GlobalNav（NavItem × 画面。§2.1 の順。先頭はホーム）
└─ MainContent（Screen を1つマウント。起動時はホーム）
```

### ヘッダの更新

- [更新] はホーム / 設定 と同じ更新パイプライン（Sync → Analyze）を起動する
- 更新中はヘッダに進行表示し、MainContent はブロックしない

### ナビ項目

ホーム / 募集馬 / 調教師 / 生産牧場 / 血統 / 設定
