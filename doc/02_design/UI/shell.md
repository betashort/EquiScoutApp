## レイアウト

| 項目 | 決定 |
|------|------|
| デバイス | **デスクトップ優先**（主に Windows、macOS 対応） |
| 全体 | ヘッダ（タイトル / グローバルナビ / 更新 / 最終更新）＋ MainContent |
| 読取方向 | 上→下。分析本文は1カラム縦積み（固定） |
| 起動 | MainContent に **ホーム** をマウント |

```text
┌──────────────────────────────────────────────────────────────┐
│ EquiScout │ ホーム 募集馬 調教師 生産牧場 血統 設定 │ [更新] 最終更新 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                         MainContent                          │  ← 各 Screen
│                                                              │
└──────────────────────────────────────────────────────────────┘
  ↑ ブランド     ↑ グローバルナビ（§2.1 順）              ↑ 更新操作
```

ヘッダ内の並び（左→右）:

1. ブランド「EquiScout」
2. GlobalNav（NavItem × 画面）
3. UpdateShortcut / UpdateStatusChip（右寄せ）

```text
AppShell
├─ HeaderBar
│  ├─ タイトル（EquiScout）
│  ├─ GlobalNav（NavItem × 画面。§2.1 の順。先頭はホーム）
│  └─ UpdateShortcut / UpdateStatusChip
└─ MainContent（Screen を1つマウント。起動時はホーム）
```

### ヘッダの更新

- [更新] はホーム / 設定 と同じ更新パイプライン（Sync → Analyze）を起動する
- 更新中はヘッダに進行表示し、MainContent はブロックしない

### ナビ項目

ホーム / 募集馬 / 調教師 / 生産牧場 / 血統 / 設定

## ビジュアル

| 項目 | 方針 |
|------|------|
| ブランド | ヘッダ左端に「EquiScout」を常時表示 |
