## レイアウト

- `NavCard` をリストデータ駆動で配置
- カード順は情報設計の優先どおり。骨格画面も遷移可

| 遷移先 | 主ラベル | 補助（任意・1行） |
|--------|----------|-------------------|
| S02 | 調教師を調べる | 本線・実データ |
| S01 | 募集馬を分析する | 1頭入力→ダッシュボード |
| S03 | 生産牧場を調べる | 準備中（骨格） |
| S04 | 血統を調べる | 準備中（骨格） |
| S06 | 設定・データ詳細 | 接続設定・詳細結果 |

| コンポーネント | 用途 |
|----------------|------|
| `NavCard`（U15） | ラベル・短い説明・遷移先 |

## ビジュアル

- 操作入口としてのカードのみ許容。装飾ウィジェット化しない
- 分析指標のプレビューは載せない
