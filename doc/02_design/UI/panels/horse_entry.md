## レイアウト

**フォーム・ワイヤ（フィールド配置）**

```text
┌─ 募集馬の入力 ─────────────────────────────────────────┐
│ 生年月日 [____]  性別 [v]  毛色 [v]  体重 [___] kg     │
│ 母名 [________▾]  父名 [________▾]                     │
│ 調教師 [________▾]  生産牧場 [________▾]  産地 [____] │
│ 馬主 [____________________]                            │
│ 市場取引価格 [________] 円                             │
│ 1口価格 [____]  口数 [__]   （任意・主価格の下）       │
│                              [クリア]  [分析を表示]     │
└────────────────────────────────────────────────────────┘
```

| 要素 | コンポーネント | 必須 |
|------|----------------|------|
| 生年月日〜馬主、市場取引価格 | `FormField` / `EntitySearchBox` | 必須（1口・口数のみ任意） |
| 分析を表示 / クリア | Primary / Secondary | 右下揃え |

フィールド配置は情報設計の読む順どおり: プロフィール → 血統キー → 関係者（馬主含む）→ 価格 → アクション。  
必須欠落は「分析を表示」時にフィールド単位で伝える（情報設計 §2.10）。
