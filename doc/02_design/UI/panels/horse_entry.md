## レイアウト

親画面の **HorseEntrySidebar** 内に配置。サイドバー幅に収まるよう **1カラム縦積み**。開閉の挙動は [`../horse.md`](../horse.md) に従う。

**フォーム・ワイヤ（フィールド配置）**

```text
┌─ 募集馬の入力 ─────────────┐
│ 生年月日 [____________]    │
│ 性別 [v]  毛色 [v]         │
│ 体重 [___] kg              │
│ 母名 [____________▾]       │
│ 父名 [____________▾]       │
│ 調教師 [__________▾]       │
│ 生産牧場 [________▾]       │
│ 産地 [____________]        │
│ 馬主 [____________]        │
│ 市場取引価格 [____] 円     │
│ 1口価格 [____]  口数 [__]  │
│ （任意・主価格の下）         │
│                            │
│      [クリア] [分析を表示] │
└────────────────────────────┘
```

| 要素 | コンポーネント | 必須 |
|------|----------------|------|
| 生年月日〜馬主、市場取引価格 | `FormField` / `EntitySearchBox` | 必須（1口・口数のみ任意） |
| 分析を表示 / クリア | Primary / Secondary | サイドバー内・下端右寄せ |

フィールド配置は情報設計の読む順どおり: プロフィール → 血統キー → 関係者（馬主含む）→ 価格 → アクション。  
必須欠落は「分析を表示」時にフィールド単位で伝える（情報設計 §2.10）。  
サイドバー内は縦スクロール可（ウィンドウ高に収まりきらない場合）。

---

## ビジュアル

- 必須エラーはフィールド下テキスト。赤系はトークンに従う
- フォームをカード装飾で包まない
- 狭幅サイドバー前提。横並びフィールドは最小限（性別／毛色、1口／口数など）
