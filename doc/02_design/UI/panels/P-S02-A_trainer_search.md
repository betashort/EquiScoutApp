## レイアウト

- 画面上部。候補は入力直下

```text
┌─ 調教師を探す ─────────────────────────────────────────┐
│ 名前 [________________________]                        │
│  ┌ 候補 ─────────────────────────────────────────────┐ │
│  │ 〇〇 調教師                                        │ │
│  │ △△ 調教師                                        │ │
│  └───────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

| コンポーネント | 用途 |
|----------------|------|
| `EntitySearchBox` | 名前検索 |
| `CandidateList` | 候補選択（データ繰り返し） |
| `EmptyState` | 未入力・0件案内 |
| `LoadingBlock` | 検索中 |

---

## ビジュアル

- 候補リストは表・装飾カード化しない。行選択が分かるコントラストのみ
