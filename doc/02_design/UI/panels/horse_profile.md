## レイアウト

入力フォーム（[`horse_entry.md`](./horse_entry.md)）の内容を **読取専用** で表示する。単体画面なし。編集は左サイドバーのフォーム側。

読む順は入力フォームと同じ: プロフィール → 血統キー → 関係者 → 価格。

```text
HorseProfilePanel
├─ ProfileBlock（生年月日 / 性別 / 毛色 / 体重）
├─ PedigreeKeyBlock（母名 / 父名）
├─ RelationsBlock（調教師 / 生産牧場 / 産地 / 馬主）
└─ PriceBlock（市場取引価格。任意: 1口価格・口数）
```

```text
┌─ 募集馬 ───────────────────────────────────────────────┐
│ 生年月日  YYYY-MM-DD     性別  …     毛色  …           │
│ 体重  … kg                                             │
│ 母名  …                  父名  …                       │
│ 調教師  …   生産牧場  …   産地  …                       │
│ 馬主  …                                                │
│ 市場取引価格  … 円                                     │
│ （任意）1口価格  … 円 / 口数  …                        │
└────────────────────────────────────────────────────────┘
```

| 要素 | コンポーネント | メモ |
|------|----------------|------|
| 各項目 | ラベル＋値（`FormField` の読取表示、または定義リスト） | 編集コントロールは置かない |
| 未入力・欠損 | 「—」 | [`../visual.md`](../visual.md) / 情報設計 §2.11 |
| 分析未実行時 | `EmptyState`（「分析を表示」前） | ダッシュボード Body 側の方針に従う |

データ源は HorseEntryPanel のフォーム状態（永続化は後続）。サイドバー折りたたみ時でも、入力内容をダッシュボード側で確認できることが主目的。
