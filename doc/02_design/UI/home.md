## レイアウト

読む順: **案内（上）→ 遷移カード（下）**。

データ更新の操作・進捗・最終更新はホーム内パネルでは扱わない。[`shell.md`](./shell.md) ヘッダの UpdateShortcut / UpdateStatusChip に一任する。

```text
ホーム
├─ IntroPanel              … 読む順1
└─ DestinationPanel        … 読む順2（遷移カード）
     └─ NavCard ×（募集馬 / 調教師 / 生産牧場 / 血統 / 設定）
```
