## レイアウト

読む順: **案内（上）→ 遷移カード（中）→ データ更新（下）**。

```text
ホーム
├─ IntroPanel              … 優先1
├─ DestinationPanel        … 優先2（遷移カード）
│    └─ NavCard ×（募集馬 / 調教師 / 生産牧場 / 血統 / 設定）
└─ HomeUpdatePanel         … 優先3
```

**画面ワイヤ**

```text
┌─ EquiScout ──────────────────────────────────────────────┐
│ 一口馬主の候補検討向けに、調教師・牧場・血統などを調べます │
└──────────────────────────────────────────────────────────┘
┌─ 分析・設定へ ───────────────────────────────────────────┐
│  [募集馬を分析する]   [調教師を調べる]                     │
│  [生産牧場を調べる]   [血統を調べる]                       │
│  [設定・データ詳細]                                        │
└──────────────────────────────────────────────────────────┘
┌─ データ更新 ─────────────────────────────────────────────┐
│  最終更新: YYYY-MM-DD HH:mm                                │
│  [データを更新]                                            │
│  （更新中の進捗 / 直近の成功・失敗の短い文言）             │
└──────────────────────────────────────────────────────────┘
```
