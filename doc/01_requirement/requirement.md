# EquiScout 要求分析

## 1. プロダクト概要

### 目的

* 強い競走馬を選びたい
* コスパ（強さ・価格のバランス）が良い競走馬を選びたい
* 一口馬主クラブの募集馬を選ぶための情報を分析・可視化したい

### 利用者・利用シーン

* 主な利用者: 個人の一口馬主希望者
* 利用シーン:
    * 募集期間中に候補馬を比較する
    * 通年で調教師・牧場・血統を調べる

### 対象データ範囲

* JV-DL で取得できるレース・関連マスタを対象とする

### 本文書の範囲

* 要求分析に留める。データ取り込み手順・画面詳細など設計フェーズで決める事項は記載しない

---

## 2. 「強さ」「コスパ」の定義

方針は以下とする。**計算式・定量化ルールは未定**とし、PoC で検証してから実装する。

### 強さ（方針）

* 1次指標: 重賞で勝てる確率が高い馬が強い（G1 > G2 > G3 の順で重視）
* 2次指標: 負けない馬が強い（馬券内に入り安定している、大負けしない）
* スコアの定量化、1次/2次の合成、未出走馬の代理指標、「大負け」の定義は **未定（PoC）**
* MVP では強さスコアの算出・表示は行わない

### 価格

* コスパ評価の基準は JV-DL の市場取引価格（HS）を**主**として用いる
* 理由: 市場取引価格と「出資金 × 募集口数」はほぼ同額とみなせる
* 募集馬の入力では **1口価格** と **口数** を任意の補助入力として用意する（JV-DL に口数は無いため、募集馬入力でのみ使用）
* 将来（MVP外）: 一口出資額との併用も検討する

### コスパ（方針）

* 強さ指標と価格を組み合わせて評価する
* 具体的な計算式は **未定（PoC）**
* MVP ではコスパスコアの算出・表示は行わない

### 評価の出力方針（PoC後）

* スコア（数値）とその根拠となるデータを、グラフ等で可視化する

### PoC

* 目指すこと: 未出走の募集馬に対し、説明可能な強さスコアを出せること
* 実施時期: 未定。並行検討の可能性はあるが、機能としての追加は MVP 完成後（version2 等）を想定する

## 3. 機能要求

### 3.1 操作フロー（複数機能）

1. **1頭分析**: 募集馬を1頭入力 → その馬の分析ダッシュボードを表示する
    * ダッシュボード内の分析種類はプルダウン等で切り替えられる
    * 調教師分析を選んだ場合は、同一ダッシュボード内に調教師分析（本実装の実データ）を埋め込む
2. **複数頭比較**: 複数頭を入力 → ランキング（強さ指標・コスパ指標）を表示する。1頭を選択すると 1. の分析ダッシュボードを表示する（**スコア定義確定後。MVP外**）
3. **単体分析**: 調教師 / 生産牧場 / 血統を単体で調べ、分析ダッシュボードを表示する（馬入力なし）

### 3.2 分析ダッシュボードの出力内容

以下をすべて表示できること（完成形）。

* 調教師分析
* 生産牧場（生産者）分析
* 血統分析
* 強さ・コスパの総合評価（PoC後）
* 類似馬・参考成績（定義は PoC。方針は血統類似度 / 生産牧場 / 調教師の組み合わせを検討）

表示のデフォルト状態:

* MVP では固定とする（今後拡張しやすいこと）
* ユーザーがデフォルト表示を設定可能にするのは P1 以降

### 3.3 調教師分析

* 探し方: 名前をテキスト入力し、候補から選択する
* 将来（MVP外）: 勝率ランキング等の一覧から選択できるようにする
* 表示する成績（調教師マスタ CH 等）:
    * 本年 / 前年 / 累計の賞金（本賞金・付加賞金）
    * 本年 / 前年 / 累計の着回数（1〜5着・着外）
    * 勝率・連対率・複勝率（着回数から算出）
    * 距離別着回数（芝 / ダート × 距離帯）
    * 最近重賞勝利一覧
* クラス別成績・新馬戦成績・勝ち上がり率（P1: レース成績等からの追加集計）
* 年別成績の多年推移グラフ（P1: CH は本年・前年・累計のみのため、JV-DL レース情報から追加集計する）

### 3.4 生産牧場分析

* 「生産牧場」は JV-DL の「生産者」と同一視する
* 指標:
    * まずは生産者マスタ（BR）の集計（本年・累計の賞金・着回数）
    * ToBe: 出身馬のリスト＋個別成績

### 3.5 血統分析

* 最低限見たい指標:
    * 距離適性（必須ではない）
        * JV-DL に SMILE 区分は無いため、レース実績・距離帯を SMILE へマッピングする
        * SMILE: S（スプリント） / M（マイル） / I（中距離） / L（長距離） / E（超長距離）
        * 例: 芝1600m以下 → S、1601〜2200m → M〜I、2201m以上 → L〜E（詳細は実装時に確定）
    * 馬場適性（芝 / ダート）
    * 兄弟の成績

### 3.6 募集馬の入力項目

募集馬の分析では以下を必須入力とする。

* 生年月日
* 性別
* 毛色
* 体重（募集時。JV-DL に募集時体重は無いため **手入力のみ**。勝率との相関を見る可能性があるため保存する）
* 母名
* 父名
* 調教師
* 生産牧場
* 産地
* 市場取引価格（主）
* 1口価格・口数（任意の補助入力）
* 馬主（一口クラブ名になる場合あり。例: サンデー / 社台 / シルク など）

#### 入力方法

* 馬名などをテキスト入力し、血統登録されている馬名の候補を表示して選択する（手入力 → 候補選択）

#### 市場取引価格の扱い

* 募集馬の分析では市場取引価格を主とする
* 1口価格 × 口数は募集馬入力でのみ使う補助入力
* 分析に参照・使用する馬（類似馬等）で未取引・不明の場合はそのまま扱い、コスパ評価の対象外としてもよい（強さ分析のみ可）

## 4. スコープと優先度

### MVP（最初に作る範囲）

* **本実装**: 調教師の単体分析 + 可視化
    * 名前検索 → 候補選択
    * 本年 / 前年 / 累計の賞金・着回数
    * 勝率・連対率・複勝率
    * 距離別着回数
    * 最近重賞勝利一覧
* **他機能**: 最低限の画面表示（入力フォーム等を含む）。募集馬1頭分析では、分析種類の切り替えにより調教師分析（実データ）を同一ダッシュボード内に表示できる
    * 募集馬1頭入力 → 分析ダッシュボード
    * 生産牧場の単体分析
    * 血統の単体分析
    * 類似馬・参考成績（表示枠。類似条件は未定）
* **MVPに含めない**
    * 強さ・コスパのスコアリング / 表示（PoC後 / version2 等）
    * 複数頭ランキング（強さ・コスパ）
    * 調教師の勝率ランキング一覧からの選択
    * 調教師の多年推移グラフ（P1）
    * クラス別・新馬・勝ち上がり（P1）
    * デフォルト表示のユーザー設定（P1。MVP は固定表示）
* 今後の機能拡大に備え、拡張性・保守性を重視する

### 優先度の考え方

* 分析の実装粒度の優先順: 調教師 → 生産牧場 → 血統（および総合評価の充実）
* 強さ・コスパの**方針**は各要素に共通して適用できる形で先に定め、**計算ルールは PoC で確定**する

### スコープ外

* 自動出資判断
* 予想印の自動生成
* 地方のみのデータ特化
* クラブ公式サイトのスクレイピング

### 将来機能（MVP外 / P1以降 / version2 等）

* 生産牧場分析・血統分析・類似馬の本実装（牧場は BR 集計ののち、出身馬リスト＋個別成績へ）
* 強さ / コスパ総合評価（PoC で計算式を確定してから）
* 複数頭ランキング
* 調教師の一覧（勝率ランキング等）からの選択
* 調教師の多年推移（レース成績からの追加集計）
* クラス別成績・新馬戦成績・勝ち上がり率の集計・表示
* デフォルト表示状態のユーザー設定
* 募集情報の PDF / CSV 等による一括取り込み（import）
* 一口出資額の併用
* その他外部データの追加取り込み

## 5. データソース

* 基本: JV-DL
* 当年の一口募集情報: 基本は手入力（JV-DL 外の可能性が高い）
* 募集時体重: 手入力のみ（JV-DL に項目なし）
* その他外部データ: 未定。今後追加したい（import 機能を想定）
* 取り込み対象レコードの詳細は設計フェーズで定める

### JV-DL 対応の目安

| 要求項目 | JV-DL での対応候補 | 備考 |
|---------|-------------------|------|
| 馬プロフィール | 競走馬マスタ (UM) | 生年月日・性別・毛色・血統・調教師・生産者・産地・馬主 |
| 調教師 | 調教師マスタ (CH) | 本年・前年・累計、距離別、最近重賞勝利。多年推移・クラス別等は要集計 |
| 生産牧場 | 生産者マスタ (BR) | 生産者＝牧場。まずは集計、ToBe は出身馬リスト＋個別成績 |
| 市場取引価格 | 競走馬市場取引価格 (HS) | 単位: 円。コスパ基準の主データ |
| 一口価格・口数 | （JV-DL外） | 募集馬入力の補助。手入力 |
| 募集時体重 | （JV-DL外） | 手入力のみ |
| 系統 | 系統情報 (BT) | 血統分析の補助 |
| レース成績 | 関連レースレコード | 多年推移・クラス別等の追加集計用 |

* デスクトップアプリを想定する
* Electron や Tauri などへの移植しやすい形態が望ましい

### データ更新

* 基本: アプリ起動後、更新ボタン等で手動更新する
* 設定による定期更新ができれば尚良いが、必須ではない
