# EquiScout 要求分析

## 要求

* 目的
    * 強い競走馬を選びたい
    * コスパ(強さ・価格のバランス)が良い競走馬を選びたい

* 一口馬主クラブの募集馬を選ぶための情報を分析したい
    * 分析した結果を可視化したい
    * 調教師を分析したい
        *  年別成績
            *  クラス別成績
            *  新馬戦成績
            *  勝ち上がり率
        * 成績推移
            *  年別成績の推移グラフ
    * 生産牧場を分析したい
    * 血統を分析したい

## 要求する機能

* 以下の情報を入力すると分析結果が表示される
    * 生年月日
    * 性別
    * 毛色
    * 母名
    * 父名
    * 調教師
    * 生産牧場
    * 産地
    * 市場取引価格
    * 馬主
