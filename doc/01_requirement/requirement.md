# EquiScout 要求分析

## 1. プロダクト概要

### 目的

* 強い競走馬を選びたい
* コスパ（強さ・価格のバランス）が良い競走馬を選びたい
* 一口馬主クラブの募集馬を選ぶための情報を分析・可視化したい

### 利用者・利用シーン

* 主な利用者: 個人の一口馬主希望者
* 利用シーン:
    * 募集期間中に候補馬を比較する
    * 通年で調教師・牧場・血統を調べる

### 対象データ範囲

* JV-DL で取得できるレース・関連マスタを対象とする

---

## 2. 「強さ」「コスパ」の定義

### 強さ

* 1次指標: 重賞で勝てる確率が高い馬が強い（G1 > G2 > G3 の順で重視）
* 2次指標: 負けない馬が強い（馬券内に入り安定している、大負けしない）

### 価格

* JV-DL の市場取引価格（HS）を基準とする

### コスパ

* 強さ指標と価格を組み合わせて評価する（強さ指標 + 価格）

### 評価の出力方針

* スコア（数値）とその根拠となるデータを、グラフ等で可視化する

---

## 3. 機能要求

### 3.1 操作フロー（複数機能）

1. **1頭分析**: 募集馬を1頭入力 → その馬の分析ダッシュボードを表示する
2. **複数頭比較**: 複数頭を入力 → ランキング（強さ指標・コスパ指標）を表示する。1頭を選択すると 1. の分析ダッシュボードを表示する
3. **単体分析**: 調教師 / 生産牧場 / 血統を単体で調べ、分析ダッシュボードを表示する（馬入力なし）

### 3.2 分析ダッシュボードの出力内容

以下をすべて表示できること。デフォルトの表示状態は設定可能とする。

* 調教師分析
* 生産牧場（生産者）分析
* 血統分析
* 強さ・コスパの総合評価
* 類似馬・参考成績

### 3.3 調教師分析

* 年別成績
    * クラス別成績（P1: MVP後）
    * 新馬戦成績（P1: MVP後）
    * 勝ち上がり率（P1: MVP後）
* 成績推移
    * 年別成績の推移グラフ
* MVP では調教師マスタ（CH）等で取得可能な成績（賞金・着回数など）を可視化する
* クラス別・新馬・勝ち上がりは必須だが後回しとし、追加しやすい拡張性・保守性を重視する

### 3.4 生産牧場分析

* 「生産牧場」は JV-DL の「生産者」と同一視する
* 最低限見たい指標: 出身馬の成績

### 3.5 血統分析

* 最低限見たい指標:
    * 距離適性（SMILE）
    * 馬場適性（芝 / ダート）
    * 兄弟の成績

### 3.6 募集馬の入力項目

募集馬の分析では以下を必須入力とする。

* 生年月日
* 性別
* 毛色
* 母名
* 父名
* 調教師
* 生産牧場
* 産地
* 市場取引価格
* 馬主（一口クラブ名になる場合あり。例: サンデー / 社台 / シルク など）

#### 入力方法

* 馬名などをテキスト入力し、血統登録されている馬名の候補を表示して選択する（手入力 → 候補選択）

#### 市場取引価格の扱い

* 募集馬の分析では必須とする
* 分析に参照・使用する馬（類似馬等）で未取引・不明の場合はそのまま扱い、コスパ評価の対象外としてもよい（強さ分析のみ可）

## 4. スコープと優先度

### MVP（最初に作る範囲）

* 調教師分析 + 可視化のみ
* 今後の機能拡大に備え、拡張性・保守性を重視する

### 優先度の考え方

* 分析の実装粒度の優先順: 調教師 → 生産牧場 → 血統（および総合評価の充実）
* 強さ・コスパの**定義そのもの**は、調教師・牧場・血統など各要素に共通して適用できる形で先に定める

### スコープ外

* 現時点では明示的なスコープ外はなし（未定）

### 将来機能（MVP外）

* 生産牧場分析・血統分析・強さ/コスパ総合評価の本格実装
* クラス別成績・新馬戦成績・勝ち上がり率の集計・表示
* 募集情報の PDF / CSV 等による一括取り込み（import）
* その他外部データの追加取り込み

---

## 5. データソース

* 基本: JV-DL
* 当年の一口募集情報: 基本は手入力（JV-DL 外の可能性が高い）
* その他外部データ: 未定。今後追加したい（import 機能を想定）

### JV-DL 対応の目安

| 要求項目 | JV-DL での対応候補 | 備考 |
|---------|-------------------|------|
| 馬プロフィール | 競走馬マスタ (UM) | 生年月日・性別・毛色・血統・調教師・生産者・産地・馬主 |
| 調教師 | 調教師マスタ (CH) | 本年・前年・累計成績あり。クラス別/新馬/勝ち上がりは要集計 |
| 生産牧場 | 生産者マスタ (BR) | 生産者＝牧場として扱う |
| 市場取引価格 | 競走馬市場取引価格 (HS) | 単位: 円 |
| 一口出資額・募集条件 | （JV-DL外） | 手動入力。将来は一括取り込み |
| 系統 | 系統情報 (BT) | 血統分析の補助 |

---

## 6. 非機能要求

### 利用形態

* デスクトップアプリを想定する
* Electron や Tauri などへの移植しやすい形態が望ましい

### データ更新

* 基本: アプリ起動後、更新ボタン等で手動更新する
* 設定による定期更新ができれば尚良いが、必須ではない
