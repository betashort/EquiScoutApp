## 4. データギャップ・定義不足

### Q7. 距離適性（SMILE）の扱いは？

補足: 手元の JV-DL 定義（UM/CH）には SMILE 自体は見当たらず、距離帯（芝16下/22下/22超 等）がある。

- [x] JV-DL の距離帯で代替する
- [ ] 外部データ（SMILE）を将来取り込む前提（MVP外）
- [x] 血統分析では距離適性を必須にしない
- [ ] その他
- [ ] 未定

> 回答:
> 距離をSMILEに分類する。
> ※SMILEとは、競馬における距離適性を「S（スプリント）」「M（マイル）」「I（中距離）」「L（長距離）」「E（超長距離）」といった区分で分類する方法を指します。JV-DLにはSMILE区分そのものは存在しませんが、馬のレース実績や距離帯（例：芝1600m以下＝S、1601〜2200m＝M〜I、2201m以上＝L〜E など）を参考にして、SMILE分類へマッピングすることを想定しています。
