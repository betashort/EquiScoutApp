---

## 1. 目的

PoC で得た強さ・コスパ計算を、アーキ上の **`StrengthCost` 差し替えモジュール**として Analyze パイプラインに載せられることを技術検証する。

確認すること:

- `AnalysisMaterializer` から呼べる境界（`materializeAll` / `materialize(id)` 相当）
- 結果を SQLite 分析結果テーブル相当へ書く想定 I/O
- TypeScript での集計・単純回帰の実現性（必要ならライブラリ候補）
- feature flag OFF 時に MVP 動作を壊さないこと

---

## 2. 検証仮説

1. ドメイン純ロジックを UI / Sync から分離したまま、更新時バッチでスコアを永続化できる
2. 単純な回帰・相関は TS ライブラリで足りる（大規模 ML は不要）
3. feature flag でモジュール無効化すれば、既存ユースケースに影響しない

## 4. 実施手順（案）

1. POC-01/02 の I/O を `StrengthCost` インターフェースに写す
2. 最小の Analyze スタブ（インメモリまたは一時 SQLite）を作る
3. 必要なら回帰ライブラリを1つ試す（`simple-statistics` 等）
4. feature flag の切り替えを確認する
5. 本実装への移行メモを `result.md` に書く
