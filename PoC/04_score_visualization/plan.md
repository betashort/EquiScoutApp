---

## 1. 目的

スコア（数値）とその**根拠データ**を、グラフ等で説明可能な形に落とす表現を検証する。

要求: スコアとその根拠を可視化する（PoC 後の方針）。本 PoC では本番 UI ではなく、**表現パターンと必須根拠項目**を確定する。

---

## 2. 検証仮説

1. 単一の総合スコアだけでは不十分で、1次/2次・価格・主要寄与要因の内訳が必要
2. 棒・レーダー・寄与度バーなど、少数のチャート型で十分説明できる
3. ViewModel に「解釈済みの根拠ブロック」を渡せば、UI は再計算不要（アーキ方針と整合）

---

## 3. 成功基準

| # | 基準 |
|---|------|
| S1 | 「必ず出す根拠項目」のリストがある |
| S2 | 推奨チャート種別と対応データが紐づいている |
| S3 | サンプル1頭分のモック（静的でも可）で説明レビューが通る |
| S4 | ViewModel / 根拠ブロックのスキーマ案がある |

---

## 4. 実施手順（案）

1. POC-01/02 の出力から、ユーザーが知りたい質問を列挙する
2. 根拠項目とチャート対応表を作る
3. 静的モック（Markdown / HTML / 簡易 React）で1頭分を見せる
4. レビューし、採用表現を `result.md` に確定する
