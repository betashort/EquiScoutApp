## 1. 目的

未出走の募集馬に強さスコアを付ける前提として、**調教師・生産牧場・血統などから得られる代理特徴量**が説明力を持つかを検証する。

要求の必須入力（生年月日・性別・毛色・体重・父母・調教師・生産牧場・産地・価格等）と JV-DL マスタの対応を踏まえ、「何をスコアの説明変数に使うか」を決める。

---

## 2. 検証仮説

1. 調教師成績（勝率・重賞・距離帯）は未出走馬の将来成績の有意な代理になる
2. 生産牧場（生産者）集計も同様に寄与する（ただし CH より弱い可能性）
3. 血統（父母・兄弟・距離/馬場適性の粗い代理）を加えると説明力が上がる
4. 募集時体重は保存価値はあるが、初期スコアの必須特徴量にはならない可能性がある

---

## 3. 成功基準

| # | 基準 |
|---|------|
| S1 | 採用特徴量一覧（必須 / 任意 / 除外）がある |
| S2 | 各特徴量の JV-DL / 手入力の取得経路が書かれている |
| S3 | 「効く / 効かない」の簡易検証（相関・集計比較など）記録がある |
| S4 | POC-01 に渡す特徴量ベクトル案がある |

---

## 4. 実施手順（案）

1. 要求の入力項目と JV-DL 対応表を特徴量候補に落とす
2. 既走馬で「出走前に知り得た情報のみ」にマスクしたデータセットを作る
3. 単純な集計・相関で各軸の説明力を見る
4. 採用 / 除外を決め、POC-01 用の特徴量定義を `result.md` に書く
