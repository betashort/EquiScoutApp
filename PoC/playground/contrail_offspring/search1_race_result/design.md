## 1. 目的

PC-KEIBA（JV-DL 由来）からコントレイル産駒を特定し、次の 2 点を定量的に評価する。

| ID | 目的 | 問い |
|----|------|------|
| A | 産駒のレース成績の評価 | コントレイル産駒は、同世代・同キャリア段階の中央競馬馬と比べてどの程度強いか。芝/ダート・距離・クラスに偏りはあるか |
| B | 成績の良い血統組み合わせの評価 | 母父・母系系統などの組み合わせのうち、成績が良い（かつ標本として信頼できる）ニックは何か |

一口馬主の募集馬検討（未出走馬の血統代理）に使える知見を出すことが最終的な使い道である。本調査自体はアプリ機能ではなく、血統分析・強さスコア PoC の材料とする。

---

## 2. 前提と制約

### 2.1 種牡馬キャリアの時点

調査日は **2026-08-16**。コントレイルは 2023 年産が初年度産駒。

| 生年 | 2026 年時点の馬齢 | 中央での主な実績レンジ |
|------|-------------------|------------------------|
| 2023 | 3 歳 | クラシック進行中。キャリア未完成 |
| 2024 | 2 歳 | 新馬・未勝利中心。未出走が多い |
| 2025 以降 | 1 歳以下 | 原則未出走。産駒マスタにのみ存在する可能性 |

**年齢ミックスを生の累計で比較しない。** 3 歳の通算成績と 2 歳の通算成績を同じ土俵に載せると、組み合わせ評価が壊れる。馬齢別・「同馬齢時点」の切り口を必須にする。

### 2.2 データの範囲

| 制約 | 扱い |
|------|------|
| 正本は PC-KEIBA の PostgreSQL。JV-DL 生ファイルは読まない | 要求 §1 / §5 に同じ |
| レース詳細（`jvd_ra` / `jvd_se`）は中央（JRA）が主 | 目的 A/B の詳細集計は **中央平地** を主対象にする |
| 地方・海外 | `jvd_um` の総合着回数・収得賞金で存在は把握するが、クラス・距離の分解には使わない |
| 障害 | 別集計。主指標からは除外する |
| 取消・除外・競走中止 | 出走分母から除外する（§5.3） |
| コード表（グレード・トラック・性別等） | JV-DL 定義書を正とする。本調査ノートにマップ表を残す |

### 2.3 少標本

初年度〜3 世代目の種牡馬調査は、母父 mill の頭数が 1〜数頭になりやすい。目的 B では **点推定の順位表を最終成果にしない**。信頼区間・最小標本・種牡馬平均への縮小を必須にする（§7.4）。

## 3. 対象母集団

層を分けて数える。混同しない。

```text
SK 産駒（コントレイルを父に持つ登録産駒）
 └─ UM 競走馬（JRA 競走馬マスタに載った馬）
      ├─ 未出走
      └─ 出走経験あり（SE に有効走が 1 以上）
           ├─ 勝利馬
           ├─ オープン／重賞出走馬
           └─ 重賞勝利馬（G1 / G2 / G3）
```

| 層 | 定義 | 主な用途 |
|----|------|----------|
| P0 産駒 | `jvd_sk.ketto_joho_01a` = コントレイルの繁殖登録番号 | 供用規模・未登録の把握 |
| P1 競走馬 | `jvd_um.ketto_joho_01a` = 同番号 | 登録率、賞金累計、着回サマリ |
| P2 出走馬 | P1 かつ有効走 ≥ 1 | 率指標の分母（馬単位） |
| P3 有効走 | P2 の各走（中央平地・異常除外） | 率指標の分母（レース単位） |

P0 ⊃ P1 を仮定する。SK に無く UM にだけ居る場合は抽出バグとして記録する。

## 4. データ取得

接続は PoC 既存の PostgreSQL（`PoC/playground/data.ipynb` のエンジン）を使う。スキーマ根拠は `doc/external_data/PC-KEIBA/*.csv`。

### 4.1 使うテーブル

| テーブル | 役割 |
|----------|------|
| `jvd_hn` | コントレイルの繁殖登録番号を解決。母・母父の名前解決 |
| `jvd_sk` | 産駒一覧（未登録馬を含む） |
| `jvd_um` | 競走馬プロフィール、3 代血統（番号+馬名）、累計賞金・着回 |
| `jvd_se` | 馬毎レース（着順・賞金・タイム・人気） |
| `jvd_ra` | レース条件（距離・トラック・グレード・競走条件） |
| `jvd_bt` | 繁殖馬の系統 ID・系統名（母父・母母の系統ラベル） |
| `jvd_hs` | 市場取引価格（任意。コスパ接続・セレクション把握） |
| `jvd_br` | 生産者名の正規化（任意） |
| `jvd_av` | 出走取消・競走除外の突合（任意。SE の異常区分を主とする） |

使わない（本調査の主経路にしない）: オッズ系 `jvd_o*`、票数 `jvd_h*`、調教 `jvd_hc` / `jvd_wc`。人気は `jvd_se.tansho_ninkijun` で足りる。

### 4.2 コントレイルの識別

馬名照合は表記ゆれに注意する。先に候補を列挙してから番号を固定する。

```text
1. jvd_hn で bamei が「コントレイル」の行を出す
2. 生年 2017、父がディープインパクトであることを ketto_joho_01a / 馬名で確認
3. hanshoku_toroku_bango を CONTRAL_HN として以降のキーにする
4. ketto_toroku_bango も控える（UM 本人行の突合用）
```

産駒の父リンクは **繁殖登録番号** である。

- UM の 3 代血統は JV-DL どおり「父・母〜母母母」。`ketto_joho_NNa` = 繁殖登録番号、`ketto_joho_NNb` = 馬名（[`JV-DL_hourse.yaml`](../../../doc/external_data/JV-DL/JV-DL_hourse.yaml)）
- SK は番号のみ（`ketto_joho_01a`〜`14a`）
- HN / HS も父・母は繁殖登録番号

したがって産駒抽出は次で足りる。

```text
jvd_sk.ketto_joho_01a = CONTRAL_HN
jvd_um.ketto_joho_01a = CONTRAL_HN
```

馬名「コントレイル」を産駒側に直接掛けない（同名リスクと、未命名馬の取りこぼし）。

### 4.3 3 代血統の位置

UM / SK の `ketto_joho_01`〜`14` は次の意味で使う。実施時に 1 頭分を目視確認してから全件に適用する。

| 番号 | 関係 | 本調査での役割 |
|------|------|----------------|
| 01 | 父 | 抽出キー（常にコントレイル） |
| 02 | 母 | 母馬単位の兄弟・母の産駒成績 |
| 03 | 父父 | 固定（ディープインパクト想定） |
| 04 | 父母 | 固定（ロードクロサイト想定） |
| 05 | 母父 | **目的 B の主軸（ニック）** |
| 06 | 母母 | 母系の近親 |
| 07〜10 | 父方 3 代 | インブリード検出の参照 |
| 11 | 母父父 | 母父の父系（サンデー系・ミスプロ系など） |
| 12 | 母父母 | 補助 |
| 13 | 母母父 | 母系のもう一段 |
| 14 | 母母母 | 補助 |

系統ラベルは `jvd_bt.hanshoku_toroku_bango` を 05 / 11 / 13 に結合して付与する。系統が無い繁殖馬は「系統不明」とし、落とさない。

### 4.4 レース結合キー

`jvd_se` と `jvd_ra` は次の 6 キーで結合する。

```text
kaisai_nen + kaisai_tsukihi + keibajo_code
+ kaisai_kai + kaisai_nichime + race_bango
```

馬の紐付けは `ketto_toroku_bango`。

### 4.5 抽出パイプライン

```text
[0] HN で CONTRAL_HN を確定（目視）
[1] SK → 産駒キー一覧（血統登録番号、生年、3代番号）
[2] UM を血統登録番号で left join（未登録を残す）
[3] HN で母・母父の名前を解決。BT で系統を付与
[4] SE を産駒キーで絞り、RA を結合
[5] 有効走フラグを付与（§5.3）
[6] 馬単位サマリと走単位ファクトを永続化（ノートの中間表 / parquet）
```

中間成果は再実行可能なこと。生の全テーブルを毎回フルスキャンしない。

### 4.6 データ品質チェック（抽出直後に必須）

| チェック | 期待 |
|----------|------|
| HN のコントレイルは 1 頭 | 複数なら生年・父で一意化。それでも複数なら停止 |
| SK 件数 ≥ UM 件数 | 逆転したらキー誤りを疑う |
| UM の `ketto_joho_01b` が「コントレイル」 | 不一致率を出す。高ければ番号の取り違え |
| 生年が 2022 未満の産駒 | ほぼ 0。居たら抽出条件を見直す |
| SE にあって UM に無い馬 | 件数を記録。原則 P1 外として詳細集計から外す |

## 5. 指標

要求 §2 の強さ方針に合わせ、**1 次（重賞で勝てるか）と 2 次（負けにくいか）を混ぜない。** 合成スコアは本調査では作らない。

### 5.1 距離・馬場の区分

要求 §3.6 の SMILE は PC-KEIBA に無いので、`jvd_ra.kyori` とトラックから仮マップする。本調査の仮境界（実装時に変えうる）:

| SMILE | 距離（m） | メモ |
|-------|-----------|------|
| S | 〜1400 | スプリント |
| M | 1401〜1600 | マイル |
| I | 1601〜2000 | 中距離 |
| L | 2001〜2400 | 長距離 |
| E | 2401〜 | 超長距離 |

芝 / ダートは `jvd_ra.track_code` をコード表で分類する。障害は除外。馬場状態は `jvd_ra` の芝・ダート馬場コードを良 / 稍重 / 重 / 不良に畳む。

### 5.2 クラス

`jvd_ra.grade_code` と `kyoso_joken_code` / `kyoso_shubetsu_code` から次の階層に畳む。コード値は定義書を見てノートに表を残す。

```text
新馬 → 未勝利 → 1勝クラス → 2勝クラス → 3勝クラス
 → オープン（非重賞） → Listed → G3 → G2 → G1
```

1 次指標は **G1 > G2 > G3 > Listed / OP** の順で見る。新馬・未勝利の勝率だけで種牡馬を評価しない（出走機会と相手関係が違うため）。

### 5.3 有効走

次をすべて満たす走を有効走とする。

- `jvd_se.ijo_kubun_code` が正常（取消・除外・競走中止等を除く）
- 確定着順が付いている
- `jvd_ra` 上で平地（障害ではない）
- 中央開催（SE/RA に載っている走）

同着は着順どおり 1 着扱い（連対・複勝の判定は確定着順 ≤ 2 / ≤ 3）。

着回数 18 桁（1〜5 着 + 着外が各 3 桁）は UM サマリの検算にだけ使う。主集計は SE から積み上げる（クラス・距離を切るため）。

賞金の単位は定義書どおり **百円**。表示・比較時に円へ換算し、換算した旨を注記する。

### 5.4 馬単位指標（P1 / P2）

| グループ | 指標 | 目的 |
|----------|------|------|
| 規模 | 産駒数、登録数、出走数、出走率 | 母集団 |
| 1 次 | 重賞出走の有無、G3 以上勝利、G2 以上、G1 勝利。オープン勝ち | A |
| 2 次 | 勝利数、連対数、複勝数。勝率・連対率・複勝率（有効走分母） | A |
| 賞金 | 平地本賞金累計、有効走 1 走あたり本賞金 | A / B |
| 適性 | 芝/ダ最多勝利距離帯、SMILE 別複勝率（走数が足りる馬のみ） | A |
|  Auxiliary | 性別、生年、生産者、調教師、市場取引価格 | 層別・バイアス |

未出走馬は率の分母に入れない。出走率そのものは別指標として出す。

### 5.5 走単位指標（P3）

| 指標 | 定義 |
|------|------|
| 1 着 / 連対 / 複勝 | 確定着順 |
| 着外 | 4 着以下 |
| 獲得本賞金 | `kakutoku_honshokin` |
| 人気内訳 | 単勝人気 1〜3 / それ以外 |
| タイム差 | `time_sa`（2 次の「大負け」候補） |

「大負け」は本調査では仮定義とする: **着順が下位 1/3、または 1 着とのタイム差が 1.0 秒超**（障害・超長距離は別扱い）。確定は POC-01 に委譲してよい。

## 6. 調査 A: 産駒成績の評価

全体像 → 層別 → 同世代比較、の順で見る。

### 6.1 全体サマリ

生年別 × 性別に、P0〜P3 の件数と次を出す。

- 出走率（P2 / P1）
- 勝馬率（勝利 ≥ 1 の P2 / P2）
- 重賞出走率・重賞勝馬率
- 平地本賞金の中央値・上位 10%（平均は外れ値に弱いので併記）
- 有効走ベースの勝率・連対率・複勝率

### 6.2 適性プロファイル

有効走を切ってクロス集計する。

| 軸 | 切り口 |
|----|--------|
| 馬場 | 芝 / ダート |
| 距離 | SMILE 5 区分、および UM 既存の 16 下 / 22 下 / 22 超 |
| 馬場状態 | 良 vs 稍重以上 |
| クラス | §5.2 |
| 馬齢 | 2 歳 / 3 歳 / 4 歳 |
| 開催 | 競馬場は参考。主結論には使わない（標本が割れる） |

各セルは **有効走数、勝率、複勝率、1 走あたり賞金**。走数 < 30 のセルは「参考」と印を付ける。

### 6.3 同世代ベースライン

コントレイル産駒だけを見ると絶対水準が分からない。次を対照にする。

| 対照 | 定義 | 役割 |
|------|------|------|
| 同生年の中央登録馬 | 生年 2022 / 2023 / 2024 の `jvd_um` 全体（平地有効走） | 主対照。世代の底上げを見る |
| 同生年・父が同年デビュー級の種牡馬 | 初年度が近い種牡馬の産駒（HN の供用開始から推定） | 種牡馬間比較 |
| ディープインパクト産駒の「同じ馬齢時点」 | 任意。歴史比較は出走機会・賞金体系が違うので補助 |

比較は必ず **生年を揃える**。指標は勝馬率・複勝率・重賞勝馬率・1 走あたり本賞金。頭数差は率の信頼区間で示す。

### 6.4 解釈の型

結論は次の型で書く（数値の羅列で終わらない）。

1. 規模: 何頭登録し、何頭走ったか
2. 1 次: 重賞・G1 まで届いているか。同世代比
3. 2 次: 勝率・複勝は安定か、勝ち負けが極端か
4. 適性: 芝寄りか、距離の山は S/M/I/L のどこか
5. 限界: 2 歳世代の未完成、中央限定、少標本

## 7. 調査 B: 血統組み合わせの評価

父は固定なので、「組み合わせ」は **母側** である。

### 7.1 組み合わせの粒度

細かい順に見る。上の層で標本が足りないときだけ下へ集約する。

| 優先 | キー | 例 | 最小標本（目安） |
|------|------|----|------------------|
| 1 | 母父（`ketto_joho_05a`） | キングカメハメハ、ロードカナロア 等 | 出走馬 5 頭 または 有効走 20 |
| 2 | 母父の父系（`ketto_joho_11a` または BT 系統） | キングカメハメハ系、サンデーサイレンス系 等 | 出走馬 8 頭 または 有効走 30 |
| 3 | 母母父（`ketto_joho_13a`） | 参考 | 出走馬 5 頭 |
| 4 | インブリード有無 | サンデー / ディープが母系に入るか | 有無の 2 群比較 |
| 5 | 母馬そのもの | 兄弟が複数居る母のみ | 同一母の産駒 2 頭以上 |

母馬単位（5）は「この配合が良い」ではなく「この牝馬の産駒が良い」可能性が高い。ニック結論には使わず、例外ケースとして列挙する。

### 7.2 組み合わせの成績

各キーについて、調査 A と同じ 1 次 / 2 次を出す。加えて **コントレイル産駒全体（同じ生年構成）との差** を見る。

| 指標 | 使い方 |
|------|--------|
| 出走馬数・有効走数 | 信頼性 |
| 勝馬率、複勝率 | 2 次 |
| 1 走あたり本賞金、本賞金中央値 | 水準 |
| 重賞勝馬数・率 | 1 次 |
| 芝複勝率 vs ダート複勝率 | 適性の偏り |
| SMILE 別複勝率 | 距離の偏り |

「良い」の判定は単一指標にしない。次をすべて満たすものを **有力ニック候補** とする。

1. 最小標本を満たす
2. 1 次または 2 次の少なくとも一方が、産駒全体より良い（差の区間が 0 をまたがない、または縮小推定でも同符号）
3. 特定の 1 頭（G1 馬 1 頭）に依存していない（その馬を除いても方向が残るか）

### 7.3 1 頭依存の除去

重賞勝利馬を 1 頭除いた再集計を、上位ニックすべてに行う。除くと平凡になる組み合わせは「個体の強さ」であり、配合の再現期待は低いと書く。

### 7.4 少標本への対処

- 母父 mill を勝率だけでソートした表は成果にしない
- 率は Wilson 95% 区間、または産駒全体平均への経験ベイズ縮小を併記する
- 走数 0 の母父は「未検証」とし、悪いとも良いとも書かない
- 多重比較（母父が数十）を念頭に、p 値の並びで採択しない。事前に主軸を母父に固定している

### 7.5 交絡（組み合わせ以外の要因）

ニックに見えやすい交絡を層別または注記する。

| 交絡 | 確認 |
|------|------|
| 生産者 | 社台系に特定母父が偏る |
| 市場価格 | 高い馬が強い母父に集まりやすい（`jvd_hs`） |
| 調教師 | 有力厩舎偏在 |
| 生年 | ある母父は初年度だけ、など |
| 性別 | 牝馬比率 |

層別しても差が残る組み合わせだけを、目的 B の主結論にする。
