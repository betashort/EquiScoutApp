親調査は表集計（母父 mill・生年別成績）である。本書は同じ産駒を **血統 DAG** に載せ、良い成績の馬どうしがどこで重なるか、未出走馬をどの既走馬に近づけるかを評価する。

---

## 1. 目的

コントレイル産駒のうち成績の良い競走馬について、次を調べる。

| ID | 問い |
|----|------|
| G1 | 好成績馬の血統グラフは、他のコントレイル産駒とどこが違うか（特徴） |
| G2 | 好成績馬どうしは、父以外のどこが似ているか（類似度） |
| G3 | 未出走のコントレイル産駒（募集馬）を、好成績クラスタへ近づける指標は作れるか |

親調査の目的 B（母父ニック）は「1 つの祖先スロットの集計」である。グラフは **複数世代・複数経路・インブリード閉路** を同時に扱える。母父 mill で拾えない「母系の 2 経路で同じ祖先に当たる」「父方と母方でサンデーが重なる」を主対象にする。

| | 親調査 [`../design.md`](../design.md) | 本書 |
|--|--------------------------------------|------|

## 3. なぜグラフか

コントレイル産駒は **父が全員同じ** ため、3 代表の 14 スロットのうち父方（01, 03, 04, 07〜10）はほぼ同一である。スロット一致率で類似を測ると、全員が似ているように見える。

グラフにすると次が明示できる。

- 共通部分（コントレイル、ディープインパクト、ロードクロサイト）を **構造として固定** し、差分は母側部分グラフに閉じる
- 同じ祖先が母父と母母父など **複数位置** に出る（インブリード）を閉路・複数親エッジとして数える
- 好成績馬集合の合併グラフで、「この祖先を共有する好成績馬が多い」をノード属性にできる

```text
好成績馬 A, B, C の血統 DAG を重ねる
        [サンデーサイレンス]     ← 父方では全員が持つ（情報量ゼロ）
              │
        [ディープインパクト]
              │
          [コントレイル]──────── 全産駒の合流点
         ／    ｜    ＼
       Aの母  Bの母  Cの母     ← 識別力はここから下（実際は上の母系）
         ＼    ｜    ／
        [共有する母父 / 母系祖先]  ← G1/G2 で見たいノード
```

## 4. グラフデータモデル

有向グラフとする。向きは **親 → 子**（血の流れ）。解析時に逆向き（子 → 祖先）へ辿る。

### 4.1 ノード

主キーは **繁殖登録番号**（`hanshoku_toroku_bango`）。競走馬で繁殖番号が空のときは血統登録番号を暫定キーにし、HN 解決できたら置換する。

| 属性 | 内容 |
|------|------|
| `id` | 繁殖登録番号（または暫定血統登録番号） |
| `name` | 馬名 |
| `sex` | 性別 |
| `year` | 生年 |
| `role_in_subject` | 対象馬から見た位置（本人 / 父 / 母 / 母父 …）。合併グラフでは持たない |
| `keito_id` / `keito_mei` | `jvd_bt`。無ければ不明 |
| `is_subject` | 産駒本人なら true |
| `generation` | 対象馬からの世代（本人 0、父母 1、…） |

系統ノードは馬ノードと混ぜない。系統は馬の属性、または後述の畳み込みグラフで使う。

### 4.2 エッジ

| 属性 | 内容 |
|------|------|
| `src` | 親の `id` |
| `dst` | 子の `id` |
| `rel` | `sire` または `dam` |

1 子につき `sire` 1、`dam` 1 を上限とする。欠ける場合はエッジを作らず、欠損として残す。

多重辺は作らない。同じ親が 2 経路で出るのは、**異なる子を経由する 2 本のエッジ** として自然に表現される（DAG であり、インブリードがあるときのみ合流する）。

### 4.3 3 種のグラフ

| 名称 | 範囲 | 用途 |
|------|------|------|
| 個体 DAG `G(h)` | 産駒 `h` と祖先（深さ D） | 特徴量、ペア類似 |
| 合併グラフ `G(S)` | 集合 S の個体 DAG の和 | 好成績クラスタの共有祖先 |
| 差分ビュー | `G(S_good)` のノードに対照比を付与 | 「好成績側で濃い」祖先 |

個体 DAG は根付きではない（親→子なので産駒が sink）。視覚化するときは産駒を下、祖先を上に置く。

### 4.4 深さ D

| 深さ | ソース | 役割 |
|------|--------|------|
| D=3 | `jvd_um` / `jvd_sk` の 14 スロット | 必須。欠損が少ない |
| D=4〜5 | `jvd_hn` を父母リンクで再帰 | インブリード・遠い共有祖先用 |
| D≥6 | 任意 | 欠損が増える。主結論に使わない |

HN 再帰の停止条件: 深さ上限、父母番号が空、既訪ノード（ループ防止）。到達できなかったスロットは欠損率として個体ごとに記録する。D=3 と D=5 で結論が変わるかだけ確認し、変わらなければ D=3 を正とする。

14 スロット → エッジへの展開（親調査 §4.3 と同じ番号）:

```text
01 父 → 本人,  02 母 → 本人
03 父父 → 01,  04 父母 → 01
05 母父 → 02,  06 母母 → 02
07 → 03, 08 → 03, 09 → 04, 10 → 04
11 → 05, 12 → 05, 13 → 06, 14 → 06
```

実施時に 1 頭を目視し、親子が逆転していないことを確認する。

## 5. 好成績ラベル

親調査の 1 次 / 2 次を、グラフの集合ラベルにする。混ぜない。

| 集合 | 定義（親調査の層・指標） | グラフでの使い方 |
|------|--------------------------|------------------|
| `S1` | P2 かつ重賞勝利（G3 以上。G1/G2 は内数として印） | 1 次の合併グラフ |
| `S2` | 生年別で、有効走 ≥ 3 かつ複勝率が産駒全体より高い馬 | 2 次の合併グラフ |
| `S_ctrl` | P2 から S1（または注目中の S）を除いた馬 | 対照 |
| `S_all` | P1（登録産駒） | 類似の探索空間 |

2 歳は有効走が少ないため、S2 に入れないか、生年別閾値にする（親調査 §2.1）。S1 は頭数が極端に少ない想定なので、**合併グラフのノード頻度は頭数そのものを併記**し、1 頭で頻度 1 の祖先を「特徴」と呼ばない。

本人ノードの成績属性（1 次フラグ、本賞金、複勝率）はノードに載せてよい。祖先ノードに成績は載せない（祖先の競走成績は本調査の範囲外）。

## 6. 特徴の評価（G1）

「好成績馬の血統の特徴」は、合併グラフ上の **対照比** で定義する。点の見た目や俗ニック名では定義しない。

### 6.1 祖先の出現

対象馬から世代 g 以内にその祖先へ到達できるか（有無）。同一馬が 2 経路ある場合は有無とは別に **経路数** と **血量** を持つ。

血量（Wright の祖先寄与）:

```text
contribution(祖先 a, 馬 h) = Σ_paths  (1/2)^{length(path)}
```

インブリードがあると同じ祖先の寄与が 1/2^g を超える。これが表スロット集計との差である。

各祖先 a について:

| 量 | 定義 |
|----|------|
| `n_good(a)` | S のうち a を祖先に持つ頭数 |
| `prev_good(a)` | n_good / \|S\| |
| `prev_ctrl(a)` | S_ctrl での同様 |
| `lift(a)` | prev_good / prev_ctrl（対照 0 のときは無限大にせず「対照ゼロ」と書く） |
| `mean_contrib_good` | S 内の平均血量 |

**特徴候補**は次をすべて満たす祖先に限る。

1. コントレイル・ディープインパクト・ロードクロサイトなど、産駒全員が持つ父方核ではない
2. `n_good` ≥ 3（S1 が 3 頭未満なら特徴候補を出さず、「標本不足」と書く）
3. lift > 1 かつ、1 頭除外しても lift の符号が残る（親調査 §7.3 と同じ）

母父（世代 2 の父）は親調査と重複する。グラフ側の新規知見は、**世代 3 以遠、複数経路、系統畳み込み**に限定して結論を書く。

### 6.2 モチーフ（部分構造）

ノード頻度で落ちる構造を別カウントする。

| モチーフ | 検出 | 見るもの |
|----------|------|----------|
| 父内インブリード | 本人から祖先 a へ 2 経路以上、かつ一方が父方 | サンデー / ディープの Tight 度 |
| 母系内インブリード | 2 経路がどちらも母方 | 母の近親配合 |
| 3/4 兄弟型 | 母父がコントレイル近親、または母がディープ産駒 | 近親クロス |
| 系統クロス | 母父の `keito` と父方核の `keito` の組 | 親調査 B のグラフ版 |

各モチーフの保有率を S vs S_ctrl で出す。頭数が足りなければ保有リストを列挙するだけにする。

### 6.3 系統への畳み込み

馬ノードを `keito_id` で畳んだグラフ `G_line(S)` を任意で作る。エッジは「系統 L1 の馬が系統 L2 の馬の親」。好成績側で太い系統エッジ（例: 母系がミスプロ系）を lift 付きで出す。系統不明は 1 ノードにまとめ、消さない。

## 7. 類似度の評価（G2）

### 7.1 父共通の補正（必須）

任意の 2 頭のコントレイル産駒は、少なくとも父経由で半兄弟である。血縁係数の下限はおおよそ 0.25 で、これ自体に識別力はない。

類似は次の **残差** で測る。

| 指標 | 定義 | 役割 |
|------|------|------|
| 祖先 Jaccard（母方） | 世代 1〜D の母方祖先集合の \|A∩B\| / \|A∪B\| | 主。説明しやすい |
| 位置つき重なり | スロット 02,05,06,11〜14 の一致に世代重み `1/2^g` | 3 代表との接続 |
| 残差血縁 r' | Wright の r(h1,h2) から、コントレイル単一祖先だけを共有する場合の r を引く | 量的な近さ |
| 血量コサイン | 祖先を次元、contribution を成分としたコサイン。父方核次元を除く | Jaccard の連続版 |

採用の第一候補は **母方 Jaccard** と **残差血縁**。両方を出し、順位が一致するか見る。一致しないペアは目視する。

グラフカーネル（WL など）は二次。解釈が落ちるので、主結論に使わない。

### 7.2 何と何を比べるか

| 比較 | 手順 | 完了条件 |
|------|------|----------|
| 好成績どうし | S1（頭数が足りれば S2）の全ペア類似 | 中央値と、S_ctrl 内ペアの中央値を比較 |
| 好成績 vs 対照 | S の各馬と S_ctrl 各馬の類似分布 | 好成績ペアより低いか |
| クラスタ | 母方 Jaccard の階層クラスタ、または残差血縁 | 母父 mill と食い違う塊があるか |

「好成績馬は互いに似ている」が成り立つのは、好成績ペアの類似が対照ペアより高いときに限る。成り立たなければ、良い成績は複数の異なる母系パターンだと書く（その場合は類似度より §6 の特徴の方が重要）。

### 7.3 未出走への延長（G3）

未出走馬 `u` ∈ P0/P1 に対し、既走の好成績集合 S との近さを 1 数にする。

```text
sim(u, S) = 中央値 { 母方Jaccard(u, s) | s ∈ S }
```

平均より中央値（外れ値の G1 馬 1 頭に引っ張られない）。参考として最近傍 3 頭の馬名と残差血縁を残す。これが POC-03「血統類似の参考成績」の種になる。

S が 3 頭未満のときは sim を出さず、最近傍列挙のみとする。

## 8. 可視化

分析は数値、図は検証と説明用。図だけで採択しない。

| 図 | 内容 | 読み方 |
|----|------|--------|
| 個体血統 DAG | 1 頭、D=3 または 5。父方を灰色、母方を本色 | 欠損・インブリード閉路の確認 |
| 好成績合併グラフ | ノード大きさ = n_good、色 = lift。父方核は固定配置で薄く | 濃い母系祖先が特徴 |
| 類似ヒートマップ | S1 ∪ 標本対照のペア類似 | 塊の有無 |
| デンドログラム | 母方 Jaccard | 母父表と食い違う枝 |

実装は playground の Python（NetworkX 等）で足りる。アプリ UI には載せない。

合併グラフが読みにくい場合の省略規則: 父方核は 1 まとめのスーパーノードにする。対照にも普遍的な祖先（lift≈1）は隠す。

## 9. 実施手順

親調査の中間表（産駒キー、14 スロット、馬単位成績）がある前提。無い場合は親調査 §8 の 1〜3 を先に行う。

| 順 | 作業 | 完了条件 |
|----|------|----------|
| 1 | 14 スロットから個体 DAG を生成。1 頭目視 | 親子方向が正しい |
| 2 | HN 再帰で D=5 を試し、欠損率を出す | D=3 を正とするか判断できる |
| 3 | S1 / S2 / S_ctrl をラベル付け | 親調査と同じ定義。頭数を記録 |
| 4 | 合併グラフと祖先 lift（§6.1） | 特徴候補 or 標本不足 |
| 5 | モチーフ保有率（§6.2） | 表 1 枚 |
| 6 | ペア類似とクラスタ（§7） | 「似ている / 複数パターン」の判定 |
| 7 | 未出走の sim(u,S) を数頭で試す | 最近傍が説明できる |
| 8 | `result.md` | 下表 |

品質チェック:

- 全産駒の個体 DAG にコントレイルノードがある
- 父方核 3 頭（コントレイル、ディープ、ロードクロサイト）の lift は ≈1（特徴候補に入らない）
- 同母兄弟の母方 Jaccard は 1 に近い
- 他人の母を持つ 2 頭の母方 Jaccard は、母父一致時に 0 より明らかに大きい
