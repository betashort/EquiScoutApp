## 1. 目的

**強さ指標と価格を組み合わせたコスパ評価**の計算式を確定する。

要求上の方針:

- 価格の主データは JV-DL の**市場取引価格（HS）**
- 1口価格 × 口数は募集馬入力の補助（JV-DL に口数なし）
- 価格不明の類似馬等はコスパ対象外としてもよい（強さのみ可）

---

## 2. 検証仮説

1. HS を主価格としたとき、「強さ / 価格」系の単純指標でも候補比較に使える
2. 価格帯で正規化（対数・分位など）しないと、高額馬が不当に不利／有利になる
3. 価格欠損時の扱い（除外 / 強さのみ表示）をルール化すれば、ランキング UI と矛盾しない

---

## 4. 実施手順（案）

1. POC-01 の強さスコア（仮でも可）を固定入力とする
2. コスパ候補式を列挙（比率・残差・分位内相対など）
3. HS 分布を確認し、正規化の要否を決める
4. 価格欠損ルールを決める
5. サンプル募集馬・既走馬で順位をレビューする
6. 採用式を `result.md` に確定する
