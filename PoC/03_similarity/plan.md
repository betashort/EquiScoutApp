## 1. 目的

募集馬・分析対象に対する**類似馬・参考成績**の定義を決める。

要求上の方針候補:

- 血統類似度
- 生産牧場
- 調教師
- それらの組み合わせ

MVP では表示枠のみ。本 PoC で「何をもって類似とするか」を確定する。

---

## 2. 検証仮説

1. 単一軸（例: 同父・同牧場のみ）では参考として弱く、複合条件の方が説明しやすい
2. 類似度スコアと、上位 N 頭の固定ルールのどちらか（または併用）が運用に耐える
3. 未出走募集馬でも、血統・牧場・調教師だけで類似候補を列挙できる

---

## 3. 成功基準

| # | 基準 |
|---|------|
| S1 | 類似条件（必須軸・任意軸・除外条件）が文書化されている |
| S2 | 類似度の計算またはマッチング手順が再現可能である |
| S3 | 「参考成績」として出す項目（着順・距離・クラス等）が定義されている |
| S4 | サンプル馬で上位類似が妥当かレビュー記録がある |
| S5 | `Similarity` モジュールの I/O 案がある |

---

## 4. 実施手順（案）

1. 類似軸の候補を列挙し、優先度をつける
2. マッチング規則（完全一致 / 部分一致 / 距離関数）を決める
3. 参考成績の表示項目を決める
4. サンプルで候補リストを生成し、妥当性をレビューする
5. 採用定義を `result.md` に確定する
